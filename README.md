## 📖 1. 适用范围

本手册旨在提供适用于 **Debian 系统** 的使用说明与配置指南，适合具备**基础 Linux 使用经验**的用户阅读。

> ⚠️ **限制说明**
> - 当前版本适用于 **Debian 13 (Trixie)**
> - 桌面环境内容主要围绕 **GNOME**
